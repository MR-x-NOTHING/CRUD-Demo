# Student CRUD Application

A Spring Boot CRUD application for managing student records.

## Technologies Used

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- MySQL
- Maven

## Features

- Add student
- Get all students
- Get student by ID
- Update student
- Delete student

## How to Run

1. Clone the repository
2. Configure MySQL
3. Update database credentials
4. Run the Spring Boot application

## API Endpoints

GET    /students
GET    /students/{id}
POST   /students
PUT    /students/{id}
DELETE /students/{id}
